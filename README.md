# منصة العربي شتاين (Alaraby Shtain) — فيزياء الثانوية العامة (مستر محمد العربي)

منصة تعليمية متطورة لمادة الفيزياء مع مستر محمد العربي، مبنية بأحدث معايير الأمان وتشفير الفيديوهات HLS + AES-128 واختبارات إلكترونية تفاعلية.

## ⚠️ ملاحظة صادقة قبل ما تبدأ
مفيش نظام "خالي من الأخطاء تمامًا" أو "غير قابل للاختراق نهائيًا" - وأي حد يدّعي عكس
ده بيكون مبالغ. اللي في المشروع ده هو أفضل الممارسات الفعلية المستخدمة صناعيًا،
مطبّقة بعناية ومتكاملة مع بعض. اختبر كل حاجة كويس قبل الإطلاق الفعلي، وابدأ بعدد
محدود من الطلاب قبل التوسع.

## الترتيب الكامل من الصفر

### 1. Supabase (مجاني)
1. أنشئ مشروع جديد على supabase.com
2. SQL Editor → نفّذ الملفات **بالترتيب التالي بالظبط**:
   - `supabase/schema.sql`
   - `supabase/schema-additions.sql`
   - `supabase/schema-branding.sql`
   - `supabase/schema-admin-trigger.sql`
   - `supabase/schema-enrollment-codes.sql`
   - `supabase/schema-features.sql`
3. Storage → أنشئ 3 buckets:
   - `encrypted-videos` (Private)
   - `video-keys` (Private)
   - `public-assets` (Public) — لرفع اللوجو وصورة المدرس عليه واستخدام الرابط في لوحة الإعدادات
4. من Project Settings → API خد: `URL`, `anon key`, `service_role key`

### 2. Upstash Redis (مجاني)
سجّل في upstash.com، أنشئ database، خد `REST URL` و`REST TOKEN`.

### 3. Resend (مجاني - لإرسال أكواد OTP)
سجّل في resend.com، خد API key.

### 4. النشر على Vercel
```bash
npm install
vercel deploy
```
أضف كل المتغيرات من `.env.example` في Vercel → Settings → Environment Variables.

### 5. أول تسجيل دخول = أنت المدرس تلقائيًا
أول حساب يتسجل في المنصة بعد النشر بيتحول تلقائيًا لـ **أدمن** (بفضل الـ trigger).
سجّل حسابك الأول فورًا بعد النشر مباشرة قبل ما تفتح المنصة للطلاب.

### 6. خصّص هويتك من لوحة الإعدادات
روح `/admin/settings` (وانت مسجل دخول كأدمن) وغيّر:
- اسم المنصة، اللوجو، الألوان
- اسم المدرس وصورته ونبذته
- رقم الهاتف والواتساب وروابط التواصل

كل ده بيتحدث فورًا لكل الطلاب بدون أي تعديل كود.

## عن الألوان والتصميم مقارنة بمنصات المدرسين المشهورين
مش هقدر (ولا ينفع قانونيًا) أنسخ هوية بصرية أو ألوان مطابقة لمنصة تعليمية معينة بعينها -
دي ملكية فكرية خاصة بيها. اللي أقدر أعمله (ومتوفر في `/admin/settings`) هو نظام ألوان
مرن بالكامل يسيطر عليه كل مدرس بنفسه حسب هويته الخاصة.

## طبقات الحماية الكاملة المطبّقة
1. تشفير الفيديو HLS + AES-128، المفتاح في bucket منفصل تمامًا
2. Buckets خاصة بالكامل - وصول فقط عبر service role من السيرفر
3. توكن JWT قصير الأجل (90 ثانية) مربوط بفيديو محدد
4. Device fingerprint مركّب (IP range + user-agent + client fingerprint)
5. جلسة واحدة نشطة فقط لكل مستخدم
6. 2FA عبر OTP بالإيميل عند أي جهاز جديد غير موثوق
7. كشف سلوك آلي وقفل تلقائي فوري + تنبيه فوري عبر webhook
8. Row Level Security على مستوى قاعدة البيانات لكل الجداول
9. التحقق الصريح من الاشتراك (enrollment) قبل أي فيديو
10. Drip content: كل فيديو له موعد فتح مستقل بعد الاشتراك
11. اتفاقية استخدام إلزامية (ToS) قبل أي وصول لأي محتوى
12. سجل تدقيق كامل لكل الطلبات + سجل أحداث أمنية منفصل
13. Security headers شاملة (CSP, X-Frame-Options, Permissions-Policy)
14. Watermark ديناميكي متحرك يحمل بيانات الطالب
15. كشف تبديل التبويب أثناء التشغيل (ردع + دليل تتبع)
16. منع path traversal في كل الروابط
17. نظام أدوار (admin/student) محمي بـ RLS

## طبقات بنية تحتية (إعدادات، مش كود) - أضفها بنفسك
- **Cloudflare CDN**: اربط دومينك بـ Cloudflare (مجاني) لإخفاء الـ origin وتفعيل WAF مجاني
- **DRM حقيقي (Widevine/FairPlay)**: ترقية مستقبلية فوق AES-128 عبر خدمات زي pallycon (لها free tier محدود)

## نظام الكورسات والدروس وأكواد الاشتراك
1. روح `/admin/courses` وأنشئ كورس جديد (اسم + وصف + سعر اختياري)
2. ادخل على الكورس → أضف الدروس واحدًا واحدًا: العنوان + **معرّف الفيديو** (نفس الـ video-id
   اللي استخدمته في `encrypt-video.sh` و`upload-video.js`) + بعد كام يوم من الاشتراك يُفتح الدرس (drip content)
3. من نفس صفحة الكورس، ولّد أكواد اشتراك بالعدد اللي تحتاجه (حتى 500 كود في المرة)،
   وانسخهم ووزّعهم على الطلاب (واتساب، فيسبوك، أي وسيلة)
4. الطالب يروح لصفحة `/redeem` بعد تسجيل الدخول، يدخل الكود، ويتفتح له الكورس تلقائيًا

**ملاحظات أمان في نظام الأكواد:**
- كل كود يُستخدم مرة واحدة بس (فيه حماية من race condition لو حاول اتنين يستخدموا نفس الكود في نفس اللحظة)
- الأكواد مش قابلة للقراءة المباشرة من العميل - كل التفعيل عبر API محمي
- تقدر تحط تاريخ انتهاء صلاحية لأي دفعة أكواد (اختياري)
- صيغة الكود (XXXX-XXXX) بتتفادى الحروف المتشابهة بصريًا (0/O، 1/I) لتقليل أخطاء النسخ اليدوي

## مميزات الأدمن الكاملة
- **إحصائيات فورية**: عدد الكورسات، الطلاب، الاشتراكات، الأكواد المتاحة (`/admin`)
- **إدارة كورسات ودروس** غير محدودة العدد (`/admin/courses`)
- **توليد أكواد اشتراك بالجملة** لكل كورس على حدة (`/admin/courses/[id]`)
- **امتحانات إلكترونية بعد كل درس**: أسئلة اختيار من متعدد، تصحيح تلقائي، نسبة نجاح قابلة للتخصيص (`/admin/quizzes/[videoId]`)
- **إدارة الطلاب**: عرض الكل، حظر/فك حظر يدوي، متابعة عدد كورسات كل طالب (`/admin/students`)
- **نشر إعلانات** تظهر فورًا لكل الطلاب أو لطلاب كورس معيّن (`/admin/announcements`)
- **تخصيص كامل للهوية**: الاسم، اللوجو، الألوان، بيانات المدرس، أرقام التواصل (`/admin/settings`)

## مميزات الطالب الكاملة
- تسجيل حساب (`/signup`) وتسجيل دخول (`/login`) وتسجيل خروج
- تفعيل كود الاشتراك (`/redeem`)
- لوحة تحكم فيها كل كورساته ودروسه، مع حالة كل درس (متاح/مقفول بموعد واضح) (`/dashboard`)
- مشاهدة الفيديو المحمي مع علامة مائية باسمه (`/course/[videoId]`)
- **امتحان تلقائي بعد كل درس** فيه امتحان، مع النتيجة فورًا
- **إشعارات/إعلانات المدرس** تظهر أعلى لوحة التحكم
- 2FA عند تسجيل الدخول من جهاز جديد

## نقاط لازم تكملها (خارج نطاق هذه الجولة بناءً على طلبك)
- نظام الدفع (Stripe/Paymob) - النظام حاليًا يعتمد على أكواد الاشتراك اليدوية فقط
- صفحة عرض قائمة الكورسات المتاحة للشراء (Landing page عامة)
- رفع الفيديوهات: `scripts/encrypt-video.sh` ثم `scripts/upload-video.js`

## أمان حرج قبل الإطلاق
- تأكد `SUPABASE_SERVICE_ROLE_KEY` مالوش بادئة `NEXT_PUBLIC_` في أي مكان
- اختبر كل الـ RLS policies بحساب طالب عادي (مش أدمن) وتأكد إنه مايقدرش يشوف بيانات حد تاني
- غيّر `VIDEO_JWT_SECRET` لقيمة عشوائية طويلة فعلية قبل النشر (`openssl rand -hex 32`)
